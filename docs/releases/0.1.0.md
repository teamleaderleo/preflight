## Summary

Preflight prepares reusable caches for an existing Starsector installation and launches the game
with reviewed optimizations that use the original game path whenever an exact check doesn't match.
Recommended mode and Balanced texture storage are the defaults. The desktop app calculates disk
requirements before preparation, keeps profiles separate, previews cleanup and removal, and can
create or send a disclosed support ZIP.

## Development performance record

The reviewed development installation progressed from a roughly 101-second worst case to a
15.25-second fastest launch. In the latest same-session comparison, five ordinary launches had an
89.00-second median and five Preflight launches had a 15.53-second median. Those figures describe
one large mod profile on one machine. The built-in benchmark lets each installation record its own
normal and accelerated launch.

## Package trust

This beta ships without paid Apple or Windows publisher identities, so those systems may show their
standard warning for an unknown developer. Every download includes a SHA-256 manifest, and desktop
updates also require Preflight's embedded updater signature. Starsector, mods, saves, and game files
remain outside Preflight's update, cleanup, and removal targets.
