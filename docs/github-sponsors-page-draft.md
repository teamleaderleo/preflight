## Introduction

I make stuff that tends to become much larger than I expect.

Right now, most of my public work is going into Preflight, a free and open-source performance
launcher for Starsector.

It started because my 83-mod Starsector installation could take 101 seconds to reach the main menu.
The latest controlled comparison on that same setup had an 89.00-second normal-launch median and a
15.53-second Preflight median, with one launch reaching 15.25 seconds.

The project now includes a built-in before-and-after startup benchmark, Starsector playtime tracking,
named mod profiles, common game settings beside Launch, extended battle-size controls, storage
planning and recovery, privacy-conscious support tools, signed updates, cross-platform package
lifecycle checks, a full CLI over the same engine, and a read-only mod linter.

A lot of the work is the part users never see until something goes wrong. Runtime shortcuts are
pinned to the code they were reviewed against and decline to the original game path on drift. The
updater is signed and rollback is rehearsed. Incompatible cache formats can coexist so rolling the
application back does not first destroy the data the older version understands. Native packages
carry a machine-readable capability receipt describing their commands, writes, child processes,
links, and network endpoints. Release artifacts are prepared with checksums, dependency inventory,
CycloneDX SBOMs, privacy/limitations material, and exact-package verification.

The repository keeps the experiment history too, including ideas that failed, measurements that
turned out to be wrong, and the tests that came out of both. I would rather leave the embarrassing
counterexample in the history than quietly delete the reason a current check exists.

Sponsorship helps pay for development time, testing hardware, hosting, release work, compatibility
research, and future projects. Preflight remains free and open source. Sponsors do not get a
different application or a private feature set; the tiers are simply different ways to support the
work.
