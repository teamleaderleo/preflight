## First public post

### Preflight

Preflight is a free, open-source launcher and performance tool for Starsector. On my heavily modded
installation, the worst startup I recorded was 101 seconds. The fastest run so far is 15.25 seconds.

It prepares and reuses work the game would otherwise repeat. It leaves the game, mods, and saves
alone, and skips runtime optimizations when the code doesn't match the version they were reviewed
against.

This Patreon is for anyone who wants to support the project. It helps pay for release hosting,
testing, and maintenance. Builds, features, and support remain public.

Project: <https://github.com/teamleaderleo/preflight>
