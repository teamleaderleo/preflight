## About

I make software and other things.

Right now, most of my public work is going into Preflight, a free and open-source fast launcher for
Starsector.

On my 83-mod M5 MacBook Air development setup, startup moved from roughly **101 seconds to a
13.69-second best run**, about a **7.4× speedup**. Preflight includes its own normal-versus-Preflight
benchmark, so you can measure your installation too.

It also tracks Starsector playtime, puts the useful game settings beside Launch, checks large mod
setups, plans its own storage before writing, handles repair and recovery, ships signed updates, and
includes a mod linter. The desktop and terminal versions use the same Java engine.

Membership helps support development time, testing hardware, hosting, release work, and future
projects. Preflight stays free and open source; the app, source, features, and public support remain
available to everyone.

## First current public post

### Preflight is getting close

I’ve been making Preflight, a free and open-source fast launcher for Starsector.

On my current 83-mod M5 MacBook Air setup, early development launches reached roughly **101
seconds**. The best current run is **13.69 seconds**, about a **7.4× speedup**. The desktop has the
same normal-versus-Preflight benchmark so you can measure your own setup.

Current features:

- **Tracked playtime!!!!!**
- Faster campaign-map movement on my setup.
- Battle size up to **2,147,483,647 deployment points** (`INT32_MAX`).
- Resolution, fullscreen, sound, antialiasing, UI scale, RAM, and battle size beside Launch.
- Mod dependency/setup checks.
- A mod linter.
- Storage planning, repair, cleanup, and recovery.
- Signed updates.
- A wireframe Hangar generated from installed ships.
- Windows, macOS, and Linux desktop packages with their own Java runtime.

On my current setup, the learned Compact data settles around **1.1 GB**. First preparation needs more
working room; Preflight calculates the actual requirement before it starts writing.

Runtime shortcuts are checked against the code they expect. If one does not match, it steps aside and
the normal game path runs.

The first public beta is now mostly release-candidate work: freezing the package set, running the
packaged benchmark, exercising the exact Windows/Linux/macOS artifacts, and finishing the release
evidence tied to those bytes.

Preflight will remain free and open source. This Patreon supports the time, testing hardware,
hosting, and release work behind it.

Project: <https://github.com/teamleaderleo/preflight>

## Follow-up posts worth writing

These should stay separate. Each one has enough material to stand on its own.

### How 101 seconds became 13.69

The startup chronology: texture prefetch, shared data reads, generated bytecode, storage layout,
Rosetta/JVM work, and the rejected experiments along the way.

### The cache was on the wrong side of the queue

The texture story: a cache with healthy hit counters could still lose because the loading thread had
already waited behind the single-threaded prefetch queue.

### 36,332 generated classes were 280 classes

The Janino story: repeated compilation first, then the much larger persisted duplication that only
became visible after compilation got cheap.

### The same texture pack, in a different order

Why the same logical Compact texture corpus launched in 14.174 seconds in observed startup order and
33.53 seconds in alphabetical order.

### Starsector has a playtime counter now

How Preflight follows the sessions it launches even when the desktop minimizes or exits afterward.

### Battle size: 2,147,483,647

The vanilla slider is not the value limit. Preflight writes Starsector’s own `battleSize` preference
and accepts the positive Java-integer range the game consumes.

### I pointed the profiler at the mods

The linter story: progressive JPEG decoding, asset/config findings, calibration across real mods, and
why the useful result is usually no finding at all.

### What exactly can this launcher touch?

Runtime fallback, explicit settings writes, signed updates, rollback, support data, and the package
capability receipt.

### How Preflight draws installed ships

The Hangar: installed hull discovery and local sprite tracing into Preflight’s own wireframe geometry
without packaging Starsector artwork.
