## Preflight: 101-second launches down to 15.25 seconds

I have 83 mods installed. At its worst, Starsector took 101 seconds to reach the main menu. The
fastest launch I have recorded with Preflight is 15.25 seconds.

So, here it is.

Preflight is a free, open-source launcher for Starsector. It prepares work that the game and your
mods would otherwise repeat every time they start. As long as the game and mod files remain the
same, it can reuse the answer.

I ran a new comparison after reaching the current result. Five ordinary launches had an
89.00-second median. Five Preflight launches had a 15.53-second median. The app includes the same
normal-versus-Preflight benchmark, so you can get a number for your own machine instead of trying
to extrapolate from mine.

**Download:** https://github.com/teamleaderleo/preflight/releases/latest

### WORLD FIRST: Starsector finally has a playtime counter

Somehow, Starsector has never had one. The usual workaround has been adding the game to Steam as a
non-Steam shortcut. As far as I can find, Preflight is the first dedicated playtime tracker for
Starsector.

It records how long the game remains open across launches Preflight can observe. The history stays
local, survives the desktop minimizing or quitting after launch, and backfills older Preflight run
evidence when available. It cannot reconstruct playtime from before Preflight was installed.

### What it does

Most of the speed comes from caching textures, merged mod data, generated bytecode, and audio. The
live optimizations run inside the game process and disappear when the game exits. Resolution,
battle size, RAM, antialiasing, UI scale, fullscreen, and sound are available beside the launch
button.

Preflight keeps old reports from accumulating forever and shows what it can safely clean up.
Removing the app and removing everything Preflight made are separate choices.

### What happens after an update?

Every runtime optimization is pinned to the code it was reviewed against. When a game or mod class
changes, that optimization declines and the original code runs. A new release may get fewer
speedups until Preflight catches up.

Preflight is still beta software, so bugs are possible. The Help page has a single switch that
turns runtime optimizations off, and the launch button continues to work.

### What it changes

Preflight leaves Starsector's JARs, executables, assets, activation data, mods, and saves alone. The
runtime changes exist only inside the launched game process and are gone when you quit. Prepared
data lives in Preflight's own folder.

Changing a game setting, RAM, or the enabled-mod profile through Preflight updates the same file the
game or vanilla launcher would use. Preflight shows the change and makes a backup first.

### AI assistance

Yes. I used ChatGPT (Codex) and Claude (Code) throughout development.

The repository includes the history of all the experiments that were tried. When stuff succeeded,
I made sure they would continue to succeed. When stuff failed, I figured out why, and I made sure
they wouldn't break again. In both scenarios, tests were written to make sure we maintained rigour.

Preflight checks the installed code before applying an optimization. If it doesn’t recognize
something, it leaves it alone. I tried to get the app itself to also be as performant as possible.
This should be better than Microsoft Teams.

Preflight doesn’t modify saves. Ordinary launches send nothing. Optional failed-run reports are off
until you enable them, and use the same bounded support ZIP shown in Help. This is still a beta. If
you find a problem, please report it. I will investigate.

### Privacy and network access

There is no account or ambient telemetry. Preflight checks GitHub for updates. It doesn't install
one unless you ask, and the update must pass its signature check. Failed-run reports are a separate,
remembered setting that starts off.

If something breaks, the Help page can make a support ZIP. It shows you what is inside before you
decide whether to send it. Saves, game assets, mod assets, screenshots, audio, and arbitrary logs
are excluded. The full behavior is in the [privacy statement](privacy.md).

The first beta packages are unsigned, so Apple and Windows will show a warning when they are opened.
Every download has a published SHA-256 checksum.

### Known limits

Real-game testing has been deepest on Apple silicon macOS. Windows and Linux packages pass their
automated installation and lifecycle checks, though they still need more real players. There is no
Intel Mac package in this beta.

The reviewed game version is **0.98a-RC8**. Other versions may use fewer optimizations. The default
preparation kept 4.76 GB on my 83-mod profile and required 12.92 GB free before starting, because
the safety check uses a larger worst-case figure while building. Preflight calculates both numbers
for your own profile. [Known limitations](known-limitations.md) has the rest.

### How to use it

1. Download the package for your system.
2. Open Preflight. If it doesn't find Starsector, choose the game folder.
3. Press **Prepare and launch**.

The first preparation can take several minutes on a large mod list. Later launches reuse it.
Preflight checks the available space first and offers a much smaller option when the normal cache
won't fit.
